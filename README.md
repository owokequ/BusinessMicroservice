# 🚀 Auth & Business Microservices

Микросервисная архитектура для аутентификации и управления бизнес-логикой (финансовый трекер).  
Проект демонстрирует современный подход к разработке на Java с использованием Spring Boot, JWT, Docker и CI/CD.

## 🛠️ Технологический стек

- **Java 21**
- **Spring Boot 4.x**
- **Spring Security + JWT**
- **Spring Data JPA + Hibernate**
- **PostgreSQL**
- **Liquibase**
- **Docker / Docker Compose**
- **MapStruct**
- **Lombok**
- **JUnit 5 + Mockito**
